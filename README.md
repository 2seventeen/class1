2.记录

3. 思考

- 问题1 波特率不一致的现象与原因
- 现象：串口监视器显示乱码。
- 原因：波特率是串口通信双方约定的传输速率，不一致时，数据采样节奏错位，无法正确解析字符。

- 问题2 修改 delay (1000) 数值对 LED 闪烁频率的影响
- 增大`delay()`数值 → LED闪烁变慢；
- 减小`delay()`数值 → LED闪烁变快。

ex12 ESP32网页触摸入侵报警实验记录

1. 关联实验：AP热点配网、Web服务器、GPIO触摸检测、前端交互、状态机控制
2. 实现逻辑：ESP32开启AP热点并搭建Web服务，搭载安防控制网页。系统包含撤防、布防、报警三种工作状态，仅布防状态开启触摸检测，引脚触发后自动进入报警模式，驱动板载LED高频闪烁。报警时网页同步显示红色入侵提示并弹出入侵警示弹窗，通过网页布防、撤防按钮可切换系统状态，撤防即可重置关闭警报，实现软硬件联动交互。
3. 实验结果：设备开启ESP32AP热点，终端连接热点后访问192.168.4.1即可进入控制页面。设备默认撤防状态，触摸无响应；布防后触碰触摸引脚可正常触发报警，LED闪烁、网页弹窗及状态提示同步生效。系统仅支持触摸触发报警，报警状态仅可通过撤防解除，整体响应迅速、运行稳定，软硬件联动效果良好。
