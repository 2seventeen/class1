2.记录

3. 思考

- 问题1 波特率不一致的现象与原因
- 现象：串口监视器显示乱码。
- 原因：波特率是串口通信双方约定的传输速率，不一致时，数据采样节奏错位，无法正确解析字符。

- 问题2 修改 delay (1000) 数值对 LED 闪烁频率的影响
- 增大`delay()`数值 → LED闪烁变慢；
- 减小`delay()`数值 → LED闪烁变快。

ex09 ESP32网页无极调光实验记录

1. 关联实验：AP热点配网、Web服务器、PWM调光、前端交互
2. 实现逻辑：ESP32开启独立AP热点并搭建80端口Web服务，内置精美可视化网页；网页提供滑块/数字输入两种方式调节亮度，前端通过图片GET请求异步调用`/set`接口下发0-255亮度值，ESP32接收参数后通过LEDC PWM驱动LED输出对应亮度，页面实时同步视觉灯光效果。
